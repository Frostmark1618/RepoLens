# Security Policy

## Supported Versions

RepoLens is currently maintained as a student-built, open-source project. Security fixes are handled on a best-effort basis.

| Version | Supported |
|---|---|
| `v1.0.0` | Yes |
| Older versions | No guarantee |

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately using GitHub's **Private Vulnerability Reporting** feature, if available for this repository.

Please do not disclose exploitable vulnerabilities in public issues before the maintainer has had a reasonable opportunity to investigate.

When reporting, include:

- A clear description of the potential vulnerability.
- Steps to reproduce the issue.
- The potential impact.
- Relevant logs or evidence, with secrets and personal data removed.

## Response and Disclosure

Reports will be reviewed on a best-effort basis. The maintainer will assess the report, request additional details if necessary, and determine appropriate remediation.

There is no guaranteed response or resolution time. Please allow reasonable time for investigation before public disclosure.

## Scope and Responsible Use

Do not include API keys, access tokens, passwords, private repository contents, or other sensitive information in reports.

Security reports should focus on genuine vulnerabilities in RepoLens, its application code, or its deployment configuration.
